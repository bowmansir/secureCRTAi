# 分屏窗格独立关闭

## 目标

每个分屏标题栏提供独立关闭入口。关闭窗格只清理该窗格的 PTY、Agent、Surface、输出缓存和尺寸状态；关闭主窗格时由相邻窗格原地接管。

## 边界

- [x] 副屏可独立关闭，原主屏不重连
- [x] 主屏可独立关闭，存活窗格不重连
- [x] 关闭活动窗格后选择相邻窗格
- [x] 只剩最后一个窗格时关闭整个标签
- [x] 关闭按钮具备 tooltip、键盘焦点和主题状态
- [x] 回归验证资源清理、全量测试和生产构建

## 验证结果

- `node --experimental-strip-types --test tests/*.test.ts`：151 项通过。
- `npm run build`：TypeScript 与 Vite 生产构建通过。
- `git diff --check`：通过，仅有仓库现存的行尾转换提示。
- Windows 桌面 dev 真机：创建本地左右分屏后关闭原主窗格，副窗格原位接管、终端输入保持可用、标签保持绿色在线。
- 复测发现并修复旧 PTY `exit` 迟到覆盖接管窗格状态的竞态；退役窗格事件拦截 30 秒后自动释放。
