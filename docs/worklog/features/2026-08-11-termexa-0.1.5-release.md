## 目标

将 Agent 授权降噪、执行通道生命周期和自然语言输入路由修复作为 Termexa 0.1.5 发布到
Mya stable 渠道，保留可复现提交、签名产物哈希和线上更新接口证据。

## 发布说明

- 常见只读诊断和受约束临时探针自动执行，同一业务变更尽量合并为一次确认。
- 修复命令超时、通道回收竞态及未知执行状态下的自动重复规划。
- 修复中文自然语言在 IME 或不可靠输入捕获时偶发进入 Shell 的问题。
