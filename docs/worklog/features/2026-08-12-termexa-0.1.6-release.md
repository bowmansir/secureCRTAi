## 目标

将输入路由、`htop` 非交互兼容、SSH 健康状态、当前主机高亮和单实例托盘修复作为 Termexa 0.1.6 正式发布到 GitHub 与 Mya stable，保留提交、构建、签名、哈希、生产备份和公开接口证据。

## 发布说明

- 明确 Shell 命令不再被固定 Agent 模式误接管，自然语言与命令输入保持清晰边界。
- `htop` Agent 动作统一转换为兼容的单次 `top` 快照，避免不支持参数导致循环失败。
- 健康检查执行真实 SSH 握手与认证，连接失败会及时清除陈旧在线状态。
- 当前 SSH 主机在侧栏具有主题匹配的选中背景，状态点更紧凑。
- 桌面应用启用单实例，再次启动只唤醒现有窗口，不再重复创建托盘图标。
