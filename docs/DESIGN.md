# Termexa Design System

## 设计方向

Termexa 是高频远程运维工具。界面应安静、紧凑、可扫描，重点突出连接状态、
命令结果和 Agent 当前动作。默认模式下 Agent 是终端时间线的一部分；用户显式点击顶部
AI 时进入独立的传统 AI 面板模式。

## 色彩

界面颜色只引用 `src/App.css` 中已有语义 token：

- 背景：`--bg`、`--bg-terminal`、`--bg-panel`、`--bg-elevated`
- 边框：`--border`、`--border-soft`
- 文本：`--text`、`--text-dim`
- 操作：`--accent`、`--accent-bg`
- 状态：`--ok`、`--warn`、`--danger`

深色、极夜和浅色主题必须使用同一套语义，不在组件内新增主题专用硬编码颜色。

## 字体

- 终端、命令、路径和输出：`--mono-font`
- 控件和说明：现有 UI 字体
- 时间线正文：13px，行高 1.55
- 紧凑状态与元信息：11px

## 间距与形状

- 使用 4px 网格；主要间距为 4、8、12、16px。
- 普通控件和 Block 圆角不超过 7px。
- 时间线 Block 不使用卡片套卡片；内部详情通过分隔线、缩进和背景层级表达。
- 命令、输出和执行状态必须有稳定尺寸；输入提示符属于时间线最后一项，展开详情时随内容
  自然下移，不得固定在窗口底部而与当前会话形成空白断层。

## Agent 时间线

- 用户请求：显示为当前终端提示符后的普通输入，不使用聊天气泡。
- Agent 说明：使用横向扁平区域插入终端记录，无聊天头像，以左侧状态点区分运行/成功/警告/失败。
- 命令提议：等宽字体，提供执行、修改、拒绝三个明确动作。
- 已执行过程：默认一行摘要，按需展开命令和输出。
- 最终结论：正文可直接扫描，Markdown 表格必须横向滚动。
- 运行中允许在当前提示符继续追加要求；停止是独立危险色图标按钮。
- Shell 命令与输出保持终端文本形态，不渲染为卡片。
- `Block` 只作为内部状态和上下文单位，不在产品界面要求用户理解或操作。

## 终端模板

从上到下固定为：

1. 标签栏
2. 当前会话的紧凑 `Shell / Agent` 模式条
3. 原生 Shell 记录与内联 Agent 结果组成的终端流
4. 当前 Shell 提示符输入行
5. 全局状态栏

模式条不放终端工具图标、任务胶囊、设置或其他全局操作。未进入 Agent 对话前完全使用
原生 xterm 输入；进入内联 Agent 流后，输入必须呈现为紧跟最新回复的 Shell 提示符，
不得出现输入框边框、发送按钮、固定底栏或第二套 Footer。传统 AI 模式打开时隐藏终端
内联模式条和时间线。

## 禁用清单

- 同屏同时显示右侧 AI 输入框和终端内联 Agent 输入框
- 同一终端同时出现两个输入框
- 在标签栏内放置 Shell / Agent 模式控件
- 在模式条显示终端工具图标或“当前任务”胶囊
- 用浮动卡片覆盖终端输入
- 用 emoji 充当功能图标
- 大面积渐变、玻璃拟态或装饰性背景
- Agent 执行中锁死其他标签输入
